# unraid-templates

Unraid Community Applications templates for apps by antiremy.

| App | Template | Project |
| --- | --- | --- |
| CacheParty | [templates/cacheparty.xml](templates/cacheparty.xml) | [antiremy/CacheParty](https://github.com/antiremy/CacheParty) |

Each template's `TemplateURL` points at its own raw GitHub URL, so keep file
paths stable. After changing a template, run **Validate** and **Scan** at
<https://ca.unraid.net/submit>.
